July 2026 – PresentC++23 / Win32 API

bean

Windows background file organizer

View bean on GitHub

A lightweight daemon that sorts Downloads into Windows known folders. Event-driven kernel waits and working-set trimming keep the daemon at 0% idle CPU and approximately 0.1 MB of RAM.

Inspect implementation +0x00
  • Uses MoveFileExW to probe unique destination names atomically, avoiding check-then-move races and overwrites.
  • Retries locked downloads through a queue and owns Win32 handles with a move-only RAII wrapper.
  • Reads extensions.cfg with a hand-written parser so users can remap file types without rebuilding. Falls back to built-in defaults.

Nov. 2024 – PresentC++23 / NASM / QEMU

bost

Minimal x86 operating system

View bost on GitHub

A freestanding x86 kernel and two-stage NASM bootloader, verified on real hardware and QEMU.

Inspect implementation +0x10
  • Checks A20, loads from disk through BIOS, sets up the GDT, and switches to 32-bit protected mode.
  • Uses C++23 concepts to validate VGA text formatting at compile time. The driver supports scrolling, color, and hardware cursor control.
  • Implements 64-bit division helpers and stack-smashing protection that reports to a kernel panic screen.
