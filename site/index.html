bean C++23 / Win32

Waiting for work on Windows

bean sorts Downloads into the folders Windows already knows about. I register the directory watcher before scanning, so a file that arrives during startup can still trigger another pass.

When a move fails because the file is in use, bean queues it for a retry. If the destination name is taken, it tries a new name without overwriting the original.

bost C++23 / NASM / QEMU

From boot sector to C++

I wrote a small x86 operating system to follow what happens before a kernel starts. Its assembly bootloader sets up the GDT and enters 32-bit protected mode. The kernel uses C++23 concepts to check VGA text formatting at compile time.
